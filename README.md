# 官公庁インフォ・ハブ (GovInfo Japan) & 官公需・入札判定ナビ

日本の各府省庁（デジタル庁、経済産業省、厚生労働省、総務省、首相官邸、金融庁、東京都等）の最新公表情報に加え、**官公需情報ポータルサイト（KKJ）準拠の公共調達・入札公告**を機械的に自動判定・スコアリングして案件抽出速度と応札速度を大幅に向上させるWebポータルです。

---

## 🌟 主な機能

### 1. 🏷️ 官公需・入札調達情報（機械判定モード）※新機能
- **自社プロファイル設定**:
  - 自社の「全省庁統一資格（役務の提供 A/B/C/D等級）」「営業地域」「得意分野キーワード」「除外キーワード（清掃、工事等）」を登録可能。
- **機械的適合度スコアリング（0〜100%）**:
  - 入札公告が入った瞬間に、自社資格・キーワード・地域・準備期間と自動突合してマッチ度を算出。
- **🎯 自社適合案件のみ（80%以上）ワンクリック絞り込み & 解除**:
  - 勝手に案件を非表示にするのではなく、ボタン一つで「80%以上の高適合案件」に瞬時に絞り込み、**もう一度押すだけでいつでも即座に全件表示に戻せます**。
  - しきい値（60%/70%/80%/90%）も柔軟に変更可能。
- **機械的 Go / No-Go 判定アシスタント**:
  - **【Go（応札推奨）】** / **【Review（要検討）】** / **【No-Go（見送り推奨）】**
  - 判定理由（資格合致、必須要件該当、納期余裕度など）とリスク要因を自動レポート。
  - 仕様書PDFおよび官公需ポータル公式公告への直接リンク。

### 2. 📢 省庁報道発表・政策ニュースモード
- 画面上部のタブからいつでも切り替え可能。
- 各省庁公式RSS（デジタル庁、経産省、厚労省、総務省など）からリアルタイム取得。
- 全文検索、ジャンル別絞り込み、後で見直す保存（LocalStorage）、Markdown/CSV出力。

## 🚀 起動方法

### 1. 前提条件
Node.js（v18以上推奨）がインストールされている環境。

### 2. 起動手順
```bash
# 1. プロジェクトフォルダに移動
cd gov-info-hub

# 2. 依存パッケージのインストール（初回のみ）
npm install

# 3. 開発サーバーの起動
npm run dev
```

起動後、ブラウザで **[http://localhost:5173](http://localhost:5173)** を開いてください。
（`--host` オプションにより、同一社内LAN内の他PCやスマホからもアクセス可能です）

## 📦 他の人へ共有（zip化）する際の注意点
macOSのセキュリティ保護（Gatekeeper）エラーを防ぐため、**`node_modules` および `dist` フォルダを除外してzip化**してください。

#### ターミナルでの作成コマンド（推奨）
```bash
cd /Users/kainetaylor/.gemini/antigravity/scratch
zip -r ~/Desktop/gov-info-hub.zip gov-info-hub -x "*/node_modules/*" "*/dist/*" "*/.git/*"
```
受け取った側は、解凍後に `npm install` を実行すれば数秒で自動復元されます。
